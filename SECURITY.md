# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

This is a teaching sample that runs on synthetic data. Fixes go to the
latest release only.

## Reporting a vulnerability

Email **b@wagner.codes** with a description of the problem and, if you can,
the steps or a fixture that reproduces it. Please do not open a public issue
for a security problem. You should get a reply within a week.

Reports of special interest for this sample: a record or question that gets
the model to release something without a person's approval, a way to make an
unverified citation pass the check, a way to put user data into the cached
prompt prefix, and anything that writes prompt or record text to the usage log.
